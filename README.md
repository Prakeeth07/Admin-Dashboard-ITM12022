
# Lanka Fresh Mart – Sales Dashboard

## 1. Project Overview

Lanka Fresh Mart is a small retail business with three branches in Colombo, Kandy, and Galle.

This project is a front-end web dashboard developed to help the management team monitor and compare sales performance across these branches. It presents important business information through KPI cards, interactive charts, sales tables, and branch performance rankings.

The dashboard is designed to be simple to use and accessible on desktop computers, tablets, and mobile devices.

## 2. Project Structure

The project contains four main files:

```text
ss/
├── index.html
├── style.css
├── script.js
└── README.md
```

- `index.html` – Defines the structure and content of the dashboard.
- `style.css` – Controls the layout, colours, styling, animations, and responsive design.
- `script.js` – Handles sales data, calculations, charts, and interactive features.
- `README.md` – Provides information about the project and instructions for running it.

## 3. Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structures the web pages using semantic elements. |
| CSS3 | Provides styling, layouts, animations, and responsive design. |
| JavaScript (ES6+) | Processes sales data and manages dashboard interactions. |
| Chart.js 4 | Creates interactive sales charts. |
| Google Fonts | Uses the Inter typeface for clear and consistent text. |
| Font Awesome 6 | Provides icons for dashboard elements. |

The project uses vanilla JavaScript without frameworks such as React or Vue. No installation or build tools are required.

## 4. How to Run the Project

Follow these steps to open the dashboard:

1. Download or copy all project files into the same folder.
2. Make sure `index.html`, `style.css`, and `script.js` are in the folder.
3. Double-click `index.html` to open it in your web browser.
4. Use the dashboard to explore the sales information and interactive features.

An internet connection is required to load Google Fonts, Font Awesome, and Chart.js from their external CDNs.

## 5. Dashboard Features

### 5.1 Key Performance Indicators (KPIs)

The dashboard displays four important business metrics:

- **Total Revenue:** Combined revenue generated by all branches.
- **Total Units Sold:** Total number of units sold across the business.
- **Best Month:** Month with the highest combined revenue.
- **Best Branch:** Branch with the highest annual revenue.

These indicators give management a quick overview of the company's sales performance.

### 5.2 Sales Charts

The dashboard includes interactive charts to help users understand sales trends.

- **Monthly Revenue Chart:** Displays revenue from January to December for Colombo, Kandy, and Galle, together with their combined revenue.
- **Annual Revenue Chart:** Compares the total revenue generated by each branch across all twelve months.
- **Sales Performance Chart:** Compares monthly revenue and units sold across the full year using a combination of bars and a line.

Users can hover over chart elements to view additional sales information.

### 5.3 Branch Selection

Users can select Colombo, Kandy, Galle, or All Branches using a dropdown menu or quick-selection buttons.

The relevant sales information is updated according to the selected branch.

### 5.4 Monthly Sales Table

The sales table provides a detailed view of monthly performance, including:

- Month name and abbreviation
- Monthly revenue in LKR thousands
- Number of units sold
- Average revenue per unit
- Month-over-month revenue growth
- Percentage share of annual revenue

This information helps management identify changes in sales performance over time.

### 5.5 Quarter Filtering and Search

Users can filter sales records by quarter:

- Q1: January to March
- Q2: April to June
- Q3: July to September
- Q4: October to December
- All Year: Displays all monthly records

The search field also allows users to find specific months by typing their names.

### 5.6 CSV Export and Printing

The CSV export feature allows users to download sales data for the selected branch.

The downloaded file can be opened in spreadsheet applications such as Microsoft Excel for further analysis.

The print feature opens the browser's print interface and uses a print-friendly layout to make reports easier to read.

### 5.7 Branch Performance Ranking

The Branch Progress Ranking section compares the performance of all three branches.

Users can select a reporting period of All Year or any month from January to December. They can also select from the following ranking metrics:

- **Annual Revenue:** Ranks branches according to their total annual revenue.
- **Units Sold:** Ranks branches according to the number of units sold.
- **Revenue Growth:** Compares revenue from the first half of the year (January to June) with the second half (July to December), or with the previous month when a specific month is selected.

The ranking section includes gold, silver, and bronze badges, progress bars, and positive or negative trend indicators. Selecting a branch card opens its connected Sales Details view; when a month was selected, the table is filtered to that month.

Revenue growth is calculated using the following formula:

`Revenue Growth (%) = ((H2 Revenue - H1 Revenue) / H1 Revenue) * 100`

A positive result indicates an increase in revenue, while a negative result indicates a decrease.

### 5.8 Light and Dark Themes

Users can switch between light and dark themes using the theme toggle button.

CSS custom properties are used to manage the colour scheme, allowing the interface and charts to adapt to the selected theme.

### 5.9 Responsive Navigation

The dashboard includes navigation links for Dashboard, Sales, Reports, and Settings.

On smaller screens, a hamburger menu provides access to the navigation links. CSS animations make the mobile menu smoother to use.

## 6. Responsive Design

The dashboard uses CSS Grid, Flexbox, and media queries to support different screen sizes.

| Screen Size | Layout |
|---|---|
| Desktop (above 1024px) | Four KPI cards in one row, charts side by side, and full dashboard layout. |
| Tablet (769px–1024px) | Two KPI cards per row with layouts adapted to the available space. |
| Mobile (768px and below) | Single-column KPI cards, vertically stacked charts, compact controls, and a hamburger menu. |

This responsive design helps users access the dashboard on different devices.

## 8. Code Quality and Organization

The project follows basic web development practices to keep the code organized and easy to maintain.

- Semantic HTML elements are used to structure the website.
- HTML, CSS, and JavaScript are maintained in separate files.
- CSS variables make it easier to manage colours and themes.
- Consistent indentation and comments improve code readability.
- JavaScript event listeners handle user interactions.
- KPI values and branch rankings are calculated from the sales data.
- Media queries support different screen sizes.
- Print-specific CSS improves the presentation of printed reports.
- The viewport meta tag supports responsive layouts on mobile devices.

## 10. Conclusion

The Lanka Fresh Mart Sales Dashboard provides a convenient way to monitor and compare sales performance across three retail branches.

By combining KPI cards, interactive charts, detailed sales tables, branch rankings, and reporting features, the dashboard helps management understand business performance more clearly.

The project demonstrates how HTML5, CSS3, JavaScript, and Chart.js can be used to develop a responsive business dashboard without requiring a front-end framework.
